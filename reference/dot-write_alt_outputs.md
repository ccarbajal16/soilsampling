# Write Alternative Site Selection Outputs to Disk

Write Alternative Site Selection Outputs to Disk

## Usage

``` r
.write_alt_outputs(target_sites, alternatives, output_dir)
```

## Arguments

- target_sites:

  Data frame of target sites with environmental values.

- alternatives:

  Data frame of selected alternatives for all sites.

- output_dir:

  Character, directory to write outputs to.

## Value

A named list of file paths written.
